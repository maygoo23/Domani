Webhook Information

Domani can send webhook POST requests when domain status changes. Configure webhook alerts on each domain's detail page.

Payload example:

{
  "domain": "example.com",
  "old_status": "active",
  "new_status": "pending_delete",
  "expires_at": "2024-03-15T00:00:00+00:00",
  "days_until_expiry": -5,
  "registrar": "Namecheap Inc.",
  "timestamp": "2024-03-10T12:34:56+00:00"
}

Requests include an X-Domani-Signature header (HMAC-SHA256) when a webhook secret is configured.
